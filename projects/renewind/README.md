# ReneWind — Wind Turbine Failure Prediction

**Great Learning — Post Graduate Program in AI/ML: Business Applications**
Course: Introduction to Neural Networks · Apr 2026

Built and improved classification models for ReneWind's wind turbine
generator failures, enabling proactive maintenance and cost reduction.
The models use sensor data to identify potential failures, minimizing
false negatives and ensuring turbines are repaired before breakdown.
