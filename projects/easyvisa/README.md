# EasyVisa — Visa Approval Prediction

**Great Learning — Post Graduate Program in AI/ML: Business Applications**
Course: Advanced Machine Learning · Mar 2026

Analyzed the data of visa applicants, built a predictive model to
facilitate the visa approval process, and — based on the factors that
significantly influence visa status — recommended a suitable profile for
applicants whose visas should be certified or denied.

## Skills & Tools

- EDA
- Data Pre-Processing
- Bagging Classifier
- Boosting Classifier
- Stacking Classifier
- Hyperparameter Tuning
- Business Insights
