# SuperKart — Sales Forecasting & Model Deployment

**Great Learning — Post Graduate Program in AI/ML: Business Applications**
Course: Model Deployment · Jul 2026

SuperKart is a retail chain operating supermarkets and food marts across
various tier cities, offering a wide range of products. To optimize its
inventory management and make informed decisions around regional sales
strategies, SuperKart wants to accurately forecast the sales revenue of its
outlets for the upcoming quarter. This project builds a predictive model
and deploys it as a live prediction service.

## Skills & Tools

- EDA and Data Preprocessing
- Model Building
- Hyperparameter Tuning
- Docker
- Flask
- API Development
- Streamlit
- HuggingFace
