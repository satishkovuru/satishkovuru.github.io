# Medical Assistant — RAG-Based Healthcare Q&A

**Great Learning — Post Graduate Program in AI/ML: Business Applications**
Course: Natural Language Processing with Generative AI · May 2026

Developed a RAG-based AI solution using established medical manuals to
address healthcare information overload. The goal: apply AI techniques to
streamline clinical decision-making, analyze impact on diagnostics and
patient outcomes, and demonstrate a functional prototype for
standardizing care practices.

## Skills & Tools

- RAG (Retrieval-Augmented Generation)
- LLM
- Prompt Engineering
- Data Preprocessing
