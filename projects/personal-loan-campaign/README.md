# Personal Loan Campaign — Customer Targeting Model

**Great Learning — Post Graduate Program in AI/ML: Business Applications**
Course: Machine Learning · Feb 2026

Identified bank customers with a high likelihood of purchasing a
personal loan by analyzing key customer attributes that influence loan
acquisition. Built a predictive model that captures customer patterns and
characteristics to help the bank effectively target potential loan
buyers, improving marketing efforts and conversion rates.

## Skills & Tools

- EDA
- Data Pre-Processing
- Model Building — Decision Tree
- Model Performance Evaluation and Improvement
- Business Recommendations
